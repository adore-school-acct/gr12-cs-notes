# C2.2 - Encapsulation

## Encapsulation

- **encapsulation:** the protection of an object's data from unwanted change
- **public attributes:** attributes that can be modified outside of the object itself
- **private attributes:** attributes that are protected within the object, and cannot be modified directly outside of the object

### Public Attributes Example

```py
import random as rand

"""The class simulating a coin"""

class Coin:
	def __init__(self):
		self.sideup = "Heads"

	def toss(self):
		self.sideup = rand.choice(("Heads", "Tails"))

if __name__ == "__main__":
	coin = Coin()
	coin.toss()
	coin.sideup = "Heads"
	print(coin.sideup)
	
	"""The result is always Heads, sideup"""
```

### Making Variable Private

Use `__` to make variable private

```py
import random as rand

class Coin:
	def __init__(self):
		self.__sideup = "Heads"
		
	def toss(self):
		self.__sideup = rand.choice(("Heads", "Tails"))
	
	# Needed to read private attribute	
	def get_sideup(self):
		return self.__sideup

if __name__ == "__main__":
	coin = Coin()
	coin.toss()
	coin.sideup = "Heads" # <-- No effect!
	print(coin.get_sideup())
	
	# NO BREAKING CHANGES!
```

## Storing Classes in Modules

- Usually good practice to store classes in separate Python file
- Then, import the module to access the classes
- The module should only have a list of class defs., nothing else
- i.e. store `Coin` in `simulation.py`

*main.py*

```py
import simulation as sim

def main():
	my_coin = sim.Coin()
	# ...
```

## Parameters in Methods

Just add the parameters after `self`

Parameters added to `__init__` means you pass in arguments during instantiation

```py
class Coin:
	def __init__(self, heads_or_tails):
		self.__sideup = heads_or_tails
	
	def get_sideup(self):
		return self.__sideup

coin = Coin("Tails")
print(coin.get_sideup())
```

## Accessor and Mutator Methods

- **accessor method:** methods used to access the state of a private attribute
	- i.e. `get_sideup()` in `Coin`
	- naming convention: `get_attribute_name()`
- **mutator method:** methods used to modify the state of a private attribute
	- naming convention: `set_attribute_name()`
	- ***BAD PRACTICE:*** making a mutator method that does not validate the value being set

```py
class Wallet:
	def __init__(self):
		self.__coins = 0
		self.__bills = 0
		self.__cards = 0
	
	"""Accessor Methods"""
	
	def get_coins(self):
		return self.__coins
	def get_bills(self):
		return self.__bills
	def get_cards(self):
		return self.__cards
	
	"""Mutator Methods"""
	
	def set_coins(self, coins):
		if type(coins) == float:
			coins = round(coins)
		if 0 <= coins <= 35:
			self.__coins = coins
		elif coins > 35: self.__coins = 35
		else: self.__coins = 0
	
	def set_bills(self, bills):
		if type(bills) == float:
			bills = round(bills)
		if 0 <= bills <= 20:
			self.__bills = bills
		elif bills > 20: self.__bills = 20
		else: self.__bills = 0
	
	def set_cards(self, cards):
		if type(cards) == float:
			bills = round(bills)
		if 0 <= cards <= 10:
			self.__cards = cards
		elif cards > 10: self.__cards = 10
		else: self.__cards = 0

"""Validation in accessor methods ensure only valid values are set"""

if __name__ == "__main__":
	wallet = Wallet()
	wallet.set_cards(-5) # INVALID
	wallet.set_bills(15.1) # INVALID, rounded
	wallet.set_cards(23) # INVALID
	
	print("Coins:", wallet.get_coins())
	print("Bills:", wallet.get_bills())
	print("Cards:", wallet.get_cards())

"""
Output:
Coins: 0
Bills: 15
Cards: 10
"""
```

## Default "State of Class"

**`__str__` method:** method that prints the programmer-defined state of an object, rather than a "cryptic" default value

```py
import random as rand

class Coin:
	def __init__(self):
		self.__sideup = "Heads"
		
	def toss(self):
		self.__sideup = rand.choice(("Heads", "Tails"))
	
	# Needed to read private attribute	
	def get_sideup(self):
		return self.__sideup
	
	def __str__(self):
		return self.__sideup + " is facing up."

if __name__ == "__main__":
	coin = Coin()
	coin.toss()
	print(coin)

"""
Output:
{sideup} is facing up.
"""
```

*Python automatically prints the value returned from `__init__`*
