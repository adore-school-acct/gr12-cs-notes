# C2.1 - Classes and Objects

## Object-Oriented Programming (OOP)

- **object-oriented programming (OOP):** a style of programming that involves organizing related code into objects
	- i.e. a Box object storing variables width, length, height
- **object:** a self-contained unit consisting of multiple pieces of data and functions to modify them
- **attribute:** data contained within an object (variables)
- **method:** functions within an object that handle the object's data

## Defining a Class

- **class:** code that describes the attributes and methods of an object
	- think of it as an object's "blueprint"
- **instantiation:** creation of an object
	- verb: to *instantiate*
- **instance:** an object created from the class
	- think of it as the final object made from the blueprint
- **class definition:** set of Python statements that define a class's data attributes

### Important Features of Python Classes

- **initializer method:** the method that sets up the data of a new object upon creation
	- called `__init__()`
	- no need to call `__init__`
	- Python auto calls it when object is creating
- **`self`:** tells Python that a certain variable is the class's attribute, rather than just a local variable
	- all attributes begin w/ `self.`
	- `self.attribute_name`
- *Accessing an object's attributes or classes*
	- `self.attribute_name`
	- `self.method_name(params)`
- **call:** telling Python to run the code of a specific method

### Example: A Coin Class

```py
import random as rand

"""The class simulating a coin"""

class Coin:
	# Initializing method
	def __init__(self):
		self.sideup = "Heads"

	# Method that modifies attribute sideup	
	def toss(self):
		choices = ("Heads", "Tails")
		self.sideup = rand.choice(choices)
	
	# Get the side up
	def get_sideup(self):
		return self.sideup

"""Using the Coin class"""

def main():
	"""Create a new coin using Coin()"""
	coin = Coin()
	# __init__ is called automatically
	# Flip the coin
	coin.toss()
	# Get the coin's state
	print(coin.get_sideup())

if __name__ == "__main__":
	main()
```

1. A `Coin` object is created
2. `sideup` is initialized to `"Heads"`
3. The `=` operator assigns the variable `coin` to the new `Coin` instance

## The 3 Pillars of OOP

- **encapsulation:** combines data and code into single object so that data is hidden from code outside of object
- **inheritance:** allows a new class to inherit properties from an existing class and extend it
- **polymorphism:** allows subclasses to replace inherited methods with their own, more appropriate methods
