# C2.4 - Polymorphism

## Polymorphism

- **polymorphism:** an object's ability to take different forms
- *2 Key Aspects*
	- Polymorphism allows superclass and subclass to have methods with same names
	- Gives program ability to call correct version of an overridden method

## Method Overriding

- **method overriding:** creating a new method in a subclass that has the same name as a method in the superclass
	- the new method takes priority
	- already done for `__init__`

*Example*

```py
"""Superclass"""

class Monster:
	def __init__(self, type):
		self.__monster = type
	def show_type(self):
		print("I am a", self.__monster)
	def make_sound(self):
		print("Grrr...")

"""Subclass"""

class Ghost(Monster):
	def __init__(self):
		super().__init__("ghost")
	def make_sound(self):
		print("Wooooo.wooooo...")

"""Run make_sound in both instances"""

def main():
	monster = Monster("beast")
	ghost = Ghost()
	print("Monster:")
	monster.show_type()
	monster.make_sound()
	print("\nGhost:")
	ghost.show_type()
	ghost.make_sound()

main()

"""
--- OUTPUT ---
Monster:
I am a beast
Grrr...

Ghost:
I am a ghost
Wooooo.wooooo...
"""
```

Notice how `make_sound` in `Ghost` is being called, rather than in `Monster`

Non-overriden methods are not affected in subclass

### `AttributeError` and `isinstance()` function

- `AttributeError`: an error raised when an object doesn't have the specified attribute or method
- `isinstance(obj, instance_of)`: a built in function that checks whether object `obj` is an instance of class in `instance_of`, returns a boolean

`AttributeError` example:

```py
class Monster:
	def __init__(self, type):
		self.__monster = type
	def show_type(self):
		print("I am a", self.__monster)
	def make_scary_noise(self):
		print("Grrr...")

class Bird:
	def __init__(self, species):
		self.__species = species
	def show_species(self):
		print("Species:", self.__species)
	def make_sound(self):
		print("Tweet tweet")

def main():
	monster = Monster("beast")
	bird = Bird("blue jay")
	monster.make_scary_noise()
	bird.make_scary_noise()

main()

"""AttributeError"""
```

`isinstance()` example

```py
class Monster:
	def __init__(self, type):
		self.__monster = type
	def show_type(self):
		print("I am a", self.__monster)
	def make_sound(self):
		print("Grrr...")

class Ghost(Monster):
	def __init__(self):
		super().__init__("ghost")
	def make_sound(self):
		print("Wooooo.wooooo...")
		
class Bird:
	def __init__(self, species):
		self.__species = species
	def show_species(self):
		print("Species:", self.__species)
	def make_sound(self):
		print("Tweet tweet")

def main():
	monster = Monster("beast")
	ghost = Ghost()
	bird = Bird("pigeon")
	
	if isinstance(ghost, Monster):
		print("Ghost is a monster")
	else:
		print("Ghost is not a monster")
	
	if isinstance(bird, Monster):
		print("Bird is a monster")
	else:
		print("Bird is not a monster")

main()

"""
---OUTPUT---
Ghost is a monster
Bird is not a monster
"""
```
