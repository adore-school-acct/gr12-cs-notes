# C3.5 - Music & Sprites

## Music and SFX

### Initializing Music

- Supported audio files: MP3, WAV, WMA, OGG
- Module: `pygame.mixer`
- Initialize (I in IDEA) music using:
	- `pygame.mixer.init()`

### Background Music

- `pygame.mixer.music.load(filepath)`
	- load background music at `filepath`
- `pygame.mixer.music.play(num_times = 0)`
	- tells pygame to start playing b.g. music
	- play music `num_times - 1` times (0 plays once, 1 plays twice)
	- if `num_times == -1`, play and repeat music indefinitely
- `pygame.mixer.music.set_volume(volume_level)`
	- `volume_level` needs to be between `0.0` and `1.0` 
	- set volume of music to `volume_level * 100`%
- `pygame.mixer.music.fadeout(time)`
	- end music after `time` milliseconds
	- volume will gradually decrease (fade) while music is being stopped

### Sound Effects (SFX)

- `sound_name = pygame.mixer.Sound(filepath)`
	- `Sound` object used to manage SFX
	- load SFX from `filepath`
	- store sound in variable `sound_name`
- `sound_name.play(num_times=0)`
	- play sound of `sound_name`
	- `num_times` works same way as b.g. music
- `sound_name.set_volume(volume_level)`
	- works same way as for b.g. music
	- only SFX is used instead

### Music and SFX Example

*Bouncing flower  example*

```py
# I - Import and Initialize
import pygame
pygame.init()
pygame.mixer.init()

def main():
     # Display
     screen = pygame.display.set_mode((640, 480))
     pygame.display.set_caption("Music and Sound Effect ")
     
     # Entities
     background = pygame.image.load("background.jfif")
     background = pygame.transform.scale(background, screen.get_size())
     
     # yellow background
     pygame.mixer.music.load("music.mp3")
     pygame.mixer.music.set_volume(1.0)
     pygame.mixer.music.play(-1)
     
     w = pygame.mixer.Sound("woosh.wav")
     w.set_volume(0.5)
     
     flower = pygame.image.load("flower.jfif")
     flower= pygame.transform.scale(flower, (40, 40))
     flower.set_colorkey((255, 255, 255))
     
     f_x = 0
     f_y = 350
     f_dir = 5
     
     # ACTION
     # Assign
     clock = pygame.time.Clock()
     keepGoing = True
     
     # Loop
     while keepGoing:
          
          # Time
          clock.tick(30)
          
          # Events
          for event in pygame.event.get():
               if event.type == pygame.QUIT:
                    pygame.mixer.music.fadeout(2000)
                    keepGoing = False
          #modify box value
          f_x += f_dir
          #check boundaries and change direction if needed
          if (f_x < 0) or (f_x > screen.get_width()-30):
               w.play()
               f_dir = -f_dir
               
          # Refresh screen
          screen.blit(background, (0, 0))
          screen.blit(flower, (f_x, f_y))
          pygame.display.flip()
          
     # Close the game window
     pygame.quit()

# Call the main function
main()
```

**Key things to note:**

- `pygame.mixer.init()` is called
- background music and sound effects defined in Entities section
- background music played
- in Event sections
	- we check if flower hits boundary
	- SFX plays when flower hits boundary

## Sprites

**sprites:** moving objects in games

*Characteristics of Sprites:*

- Visual representation
- Attributes for position and size
- Ability to move
- Ability to recognize collisions
- Dynamic birth (and death)
	- create and destroy as needed
- Self-contained
	- organized into separate code unit
	- simplifies main game loop
	- uses OOP

### Creating a Sprite

- `Sprite` class used: `pygame.sprite.Sprite`
- A class defined for each sprite, inheriting from `pygame.sprite.Sprite`
- Sprites created in "Initialize" section
- `__init__()` initializes properties of a sprite
- `update()` tells pygame what to do with a sprite during each game loop

### `image` Attribute

- `image`: attribute referring to `Surface` visually representing the sprite
- *public attribute*, due to historical poor OOP design

*Example*

```py
self.image = pygame.image.load("image.png")
```

### `rect` Attribute

`rect`: attribute assigned to a `Rect` object

Attributes and methods of `rect`:

- `top`, `bottom`, `left`, `right`: specifies `x` coord. for left / right side or `y` coord. for top / bottom side
- `topleft`, `midtop`, `topright`, `midleft`, `bottomleft`, `midbottom`, `bottomright`
	- returns `(x, y)` coordinates for specified corner or point on rect.
- `centerx`, `centery`: x and y values of rect.'s center
- `size`: (x, y) tuple giving rect.'s size in px
- `width`, `height`: width / height of rect. in px
- `colliderect(rect2)`: determines if the current rect. collided with `rect2`
- `inflate(x, y):` changes size of rect.
	- used to tweak collision routines
- `move(dx, dy)`: moves a sprite by `(dx, dy)` pixels

Creating a `rect` from an image:

- `image_var.get_rect()` creates a bounding rectangle based on the image dimensions
	- for sprites: `self.image.get_rect()`

### Sprite Groups

- **sprite group:** special group that allows you to control one or multiple sprites at the same time
- create group using `group_name = pygame.sprite.Group()`
	- pass in all sprites as arguments
- Special Methods
	- methods are called in group in this order:
	- `group_name.clear(screen, background)`
		- erases all sprites on `screen` and replaces them with `background`
	- `group_name.update()`
		- calls `update()` method of every sprite
	- `group_name.draw(screen)`
		- draw all sprites on the screen
- Display still needs to be flipped

### Sprite Example

*Flower put as a sprite:*

```py
# I - Import and Initialize
import pygame
pygame.init()

screen = pygame.display.set_mode((640, 480))

class Flower(pygame.sprite.Sprite):
     def __init__(self):
		  pygame.sprite.Sprite.__init__(self)
          
          # Set the image attribute for our Flower sprite
          self.image = pygame.image.load("flower.jfif")
          self.image = pygame.transform.scale(self.image, (40, 40))
          self.image.set_colorkey((255, 255, 255))
          # Set the rect attribute for our Flower sprite
          self.rect = self.image.get_rect()
          self.rect.left = 0
          self.rect.top = 350
    
          self.__direction = 10
          
     def update(self):
          self.rect.left += self.__direction
          if (self.rect.left < 0) or (self.rect.right > screen.get_width()):
               self.__direction = -self.__direction

def main():
     # Display
     pygame.display.set_caption("Basic Sprite Demo")
     
     # Entities
     background = pygame.image.load("background.jfif")
     background = pygame.transform.scale(background, screen.get_size())
     
     # create a Flower sprite object
     f = Flower()
     allSprites = pygame.sprite.Group(f)
     
     # ACTION
     # Assign
     clock = pygame.time.Clock()
     keepGoing = True
     # Loop
     while keepGoing:
          # Time
          clock.tick(30)
          
          # Events
          for event in pygame.event.get():
               if event.type == pygame.QUIT:
                    keepGoing = False
            
          # Refresh screen
          screen.blit(background, (0,0))
          allSprites.clear(screen, background)
          allSprites.update()
          allSprites.draw(screen)
          pygame.display.flip()
                    
     # Close the game window
     pygame.quit()

# Call the main function
main()
```

- NOTE: `screen` initialization moved from Display to Initialize
- `__direction` attribute of `Flower` is unique
- `update()`
	- flower moves left or right 10 px
	- specifically left edge is repositioned
	- if left or right edge is hit, direction of sprite is reversed
