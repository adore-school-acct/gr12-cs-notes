# C3.7 - Joysticks

## Joystick Detection

- Controller used: Logitech Gamepad F310
	- 2 modes (switch at back)
	- X = Xbox mode
	- D = PC mode
	- X mode used in class
- Joystick is optional input; must detect before using it
- MODE button swaps D-pad and thumbstick input

*Sample code*

```py
# I - Import and Initialize 
import pygame, mySprites 
pygame.init() 
screen = pygame.display.set_mode((640, 480))     
  
# Create a list of Joystick objects. 
joysticks = [] 
for joystick_no in range(pygame.joystick.get_count()): 
    stick = pygame.joystick.Joystick(joystick_no) 
    stick.init() 
    joysticks.append(stick) 
      
# Create an initial joystick status message. 
if joysticks: 
    status = "%d Joystick(s) detected." % (joystick_no+1) 
else: 
    status = "Sorry! No joystick(s) to test."
```

*Explanation:*

- creation of `joystick` list to keep track of `Joystick` objects
- `pygame.joystick.get_count()` &rarr; returns number of joysticks currently detected
- for each joystick, `Joystick` object instantiated (and given an index)

## Joystick Events

*Sample code:*

```py
def main(): 
       
    # Display 
    pygame.display.set_caption("Joystick Detection + Events demo") 
      
    # Entities 
    background = pygame.Surface(screen.get_size()) 
    background.fill((255, 255, 255)) 
    screen.blit(background, (0, 0)) 
      
    statusLabel = mySprites.Label(status, (320,240)) 
    allSprites = pygame.sprite.Group(statusLabel) 
          
    # ACTION 
      
    # Assign  
    clock = pygame.time.Clock() 
    keepGoing = True
  
    # Loop 
    while keepGoing: 
      
        # Time 
        clock.tick(30) 
      
        # Events 
        for event in pygame.event.get(): 
            if event.type == pygame.QUIT: 
                keepGoing = False
            elif event.type == pygame.JOYBUTTONDOWN: 
                statusLabel.set_text("Joystick #%d, Button #%d Down" % (event.joy, event.button)) 
            elif event.type == pygame.JOYBUTTONUP: 
                statusLabel.set_text("Joystick #%d, Button #%d Up" % (event.joy, event.button)) 
            elif event.type == pygame.JOYHATMOTION: 
                statusLabel.set_text("Joystick #%d, Hat Value #%s" % (event.joy, event.value))
            elif event.type == pygame.JOYAXISMOTION: 
                statusLabel.set_text("Joystick #%d, Axis %d, Value #%s" % (event.joy, event.axis, event.value))
                  
        # Refresh screen 
        allSprites.clear(screen, background) 
        allSprites.update() 
        allSprites.draw(screen) 
          
        pygame.display.flip() 
          
# Call the main function 
main()
```

*Joystick events:*

- `pygame.JOYBUTTONDOWN`
	- occurs when button on joystick is held down
	- `event.joy` indicates which joystick number caused event
	- `event.button` specifies which button on joystick pressed
- `pygame.JOYBUTTONUP`
	- occurs when button on joystick is released
	- same `event` attributes as above
- `pygame.JOYHATMOTION`
	- "hat" another name for D-pad
	- occurs when D-pad pressed in 1 of 8 direction
	- `event.joy` included
	- `event.value` returns `(x, y)` tuple indicating which way the D-pad was pressed
		- i.e. `(-1, 1)` for bottom left
- `pygame.JOYAXISMOTION`
	- occurs when one of the thumbsticks are moved off-center
	- `event.joy` included
	- each thumbstick has vertical and horizontal axis
	- `event.axis` indicates which axis has the thumbstick been moved
		- `0` &mdash; left thumbstick moved horizontally
		- `1` &mdash; left thumbstick moved vertically
		- `2` &mdash; right stick moved horiz.
		- `3` &mdash; right stick moved vert.
	- `event.value` determines extent of movement
		- `float` value ranging from `-1.0` to `1.0`

## Example: Controlling a `Box` Sprite

### Creating the `Box`

*Sample code:*

```py
class Box(pygame.sprite.Sprite): 

     def __init__(self, screen): 
         pygame.sprite.Sprite.__init__(self) 
           
         # Set the image attribute for our Box sprite 
         self.image = pygame.Surface((40, 40)) 

         self.image.fill((0, 0, 0)) 
           
         # Set the rect attribute for our Box sprite 
         self.rect = self.image.get_rect() 
         self.rect.left = 300
         self.rect.top = 200
         self.__screen = screen 
         self.__dx = 0
         self.__dy = 0
    
     def change_colour(self, button_num): 
         colours = [ (0,0,0), (0,0,111), (0,111,0), (0,111,111), (111,0,0),    (111,0,111), (111,111,0), (111,111,111), (0,0,222), (0,222,0) ] 
         self.image.fill(colours[button_num]) 
       
     def change_direction(self, xy_change): 
         self.__dx, self.__dy = xy_change 
           
     def update(self): 
         if ((self.rect.left > 0) and (self.__dx < 0)) or ((self.rect.right < self.__screen.get_width()) and (self.__dx > 0)): 
             self.rect.left += (self.__dx*50) 
         if ((self.rect.top > 0) and (self.__dy > 0)) or ((self.rect.bottom < self.__screen.get_height()) and (self.__dy < 0)): 
             self.rect.top -= (self.__dy*50)
```

*Explanation*

- `Box` initialized as 40 x 40 px black `Surface` w/ top-left corner at `(300, 200)`
- `__screen` keeps track of `screen Surface`
- `__dx` and `__dy` initialized to `0` to indicate no movement
- `change_colour()` method changes colour of `Box` depending on what button number pressed
- `change_direction()` takes a `(x, y)` tuple indicating direction of D-pad
	- `__dx = x`
	- `__dy = y`
- `update()` moves `Box` 5 px based on `__dx` and `__dy` unless edge of screen reached

### Main Loop

*Sample code:*

```py
# I - Import and Initialize 
import pygame, mySprites 
pygame.init() 
screen = pygame.display.set_mode((640, 480)) 
  
# Create a list of Joystick objects. 
joysticks = [] 
for joystick_no in range(pygame.joystick.get_count()): 
    stick = pygame.joystick.Joystick(joystick_no) 
    stick.init() 
    joysticks.append(stick) 
      
def main():        
    # Display 
    pygame.display.set_caption("Move the rectangle with the joystick!") 
      
    # Entities 
    background = pygame.Surface(screen.get_size()) 
    background.fill((255, 255, 255)) 
    screen.blit(background, (0, 0)) 
      
    # Create a Box sprite object 
    box = mySprites.Box(screen) 
    allSprites = pygame.sprite.Group(box) 
  
    # ACTION 
      
    # Assign  
    clock = pygame.time.Clock() 
    keepGoing = True
  
    # Hide the mouse pointer 
    pygame.mouse.set_visible(False) 
  
    # Loop 
    while keepGoing: 
      
        # Time 
        clock.tick(30) 
      
        # Events 
        for event in pygame.event.get(): 
            if event.type == pygame.QUIT: 
                keepGoing = False
            elif event.type == pygame.JOYBUTTONDOWN: 
                box.change_colour(event.button) 
                print event.button
            elif event.type == pygame.JOYHATMOTION: 
                box.change_direction(event.value) 
          
        # Refresh screen 
        allSprites.clear(screen, background) 
        allSprites.update() 
        allSprites.draw(screen) 
        pygame.display.flip() 
          
    # Unhide mouse pointer 
    pygame.mouse.set_visible(True) 
      
# Call the main function 
main()
```

*Explanation, new:*

- If button is pressed, button number passed into `change_colour()` to change colour of `Box`
- If D-pad is pressed, `(x, y)` value passed in to `change_direction()` to move `Box`
