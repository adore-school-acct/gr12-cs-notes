# C1.1 - Lists

## List

- **list:** sequence data type that can store various datatypes as items
	- lists are mutable
- **element:** the individual item stored in a list
- **sequence datatype:** object that contains multiple items of data
- **mutable:** object can be changed after creation

## Creating Lists

Method 1: Directly

```py
arr = [1, 2, 3, 4, 5, 6]
```

Method 2: `range(...)` &mdash; [[c2.4-repetition-structs]]

```py
# list = range(start, stop, step)
arr = range(1, 7)
```

Method 3: Repetition Operator (`*`)

```py
# list = [item] * n_of_repetitions
arr = [9] * 100
```

## Indexing and Slicing

Similar to indexing and slicing in strings

i.e. `arr = [1, 9, 3, 9, 4, 5]`

|1|9|3|9|4|5|
|-|-|-|-|-|-|
|0|1|2|3|4|5|
|-6|-5|-4|-3|-2|-1|

Slicing a list: `list[start:stop:step]`

### Using `in`

```py
# Find item in list

arr = ["abc", "def", 2000, "zip"]

if 2000 in arr:
	print("It's time")

# Loop over itmes in list

for item in arr:
	print(item)
```

### List Mutability

You can change lists

```py
nums = [1, 9, 4, 6]
nums[3] -= 1

for n in nums:
	print(n, end="")
```

To change items in list, you must use index

```py
nums = [1, 2, 3, 4]

print("INCORRECT")

for num in nums:
	num *= 2 # pass-by-copy

print(nums)

print("CORRECT")

for i in range(len(nums)):
	nums[i] *= 2

print(nums)
```

## Passing List to Function

- **pass-by-value / pass-by-copy:** pass a copy of the original value into the function
- **pass-by-reference:** a reference ("address") to the original list to passed to the function, the list is not duplicated
	- all mutable objects passed like this
	- done this way for space and time efficiency
	- note that when setting another variable as a list variable
		- the variable is set to the reference of the new list
	- setting a variable (even if new name) to a new list creates a new list

```py
# Demonstration of pass-by-reference

def double_list(nums):
	for i in range(len(nums)):
		nums[i] *= 2

	return nums

nums = [1, 2, 3, 4]
doubled = double_list(nums)
print("nums:", nums)
print("doubled:", doubled)
```

A `return` statement is not needed if pass-by-reference is used

### Force Pass-by-Copy

- Pass in a slice of the list into the function
- Format: `function_name(list_name[:])`
- The list contents are modified but not the list itself
- :x: Should not do unless you have specific reason to copy

## List Functions and Methods

Format: `list.method(...)` for all except for last one

|Method|Description|
|-|-|
|`append(item)`|Add `item` to end of list|
|`insert(index, item)`|Add `item` to list at index `index`|
|`remove(item)`|Remove the first occurrence of `item`|
|`reverse()`|Reverse the list|
|`sort()`|Sort the list|
|`extend(new_list)`|Add `new_list`'s items to the end of the list|
|`pop(index=-1)`|Remove and return the item at index `index` (last index if `index` left blank)|
|`index(item)`|Find index of first occurrence of `item` in list, raises `ValueError` if not found|
|`del list[index]`|Remove item at index `index`|

Other functions:

- `len(list)`: returns the number of items in `list`
- `min(list)`: returns the lowest value in `list`
- `max(list)`: returns the highest value in `list`

*Demonstration*

```py
items = ["How", "to", "win"]
print(items)
# Add an item
items.append("a game")
print(items)
# Add an item in the middle
items.insert(-2, "surely")
items.insert(-2, "100%")
print(items)
# Remove items
items.remove("surely")
removed = items.pop(-3)
print("Removed", removed)
print(items)
# Reverse list
items.reverse()
print(items)
items.reverse()
# Remove and add, special magic
del items[-1]
items.append("chess")
print(items)
```

### The split() Method

Format: `str.split()` or `str.split(sep=None, maxsplit=-1)`

- `str.split()`: splits a string at each whitespace into a list of words
- `str.split(sep=None, maxsplit=-1)` splits a string at each "`sep`", `maxsplit` number of times into a list of words
	- if `sep` is left blank, `sep` is any whitespace
	- if `maxsplit` is left blank, there is no limit to split

**Demo:**

```py
abc = "one two three"
words = abc.split()
print(words, end="\n\n")

abc = "one#two#three#four"
words = abc.split("#")
words1 = abc.split("#", 2)
print(words, '\n', words1, sep='')

"""
Output:
['one', 'two', 'three']

['one', 'two', 'three', four]
['one', 'two', 'three#four']
"""
```


## 2D Lists

- **2D list:** a list that contains other lists as its elements
	- a.k.a. *nested list*
	- common to think of 2D lists as having rows and cols.
- 2 indices required to use 2D lists

### Accessing an Element in a 2D List

```py
list_name[row][column]
```

where `row` is the index of the row, `column` is the index of the column

### Example

i.e. Make a square grid 1 to 9,

```py
grid = [[1, 2, 3],
		[4, 5, 6],
		[7, 8, 9]]
```

#### Acessing Elements in the Example

*Tabular representation of 2D list `grid`*

| |Col. 0|Col. 1|Col. 2|
|-|-|-|-|
|**Row 0**|1|2|3|
|**Row 1**|4|5|6|
|**Row 2**|7|8|9|

*Code needed to accessed each item in list `grid`*

| |Col. 0|Col. 1|Col. 2|
|-|-|-|-|
|**Row 0**|`grid[0][0]`|`grid[0][1]`|`grid[0][2]`|
|**Row 1**|`grid[1][0]`|`grid[1][1]`|`grid[1][2]`|
|**Row 2**|`grid[2][0]`|`grid[2][1]`|`grid[2][2]`|

#### Printing Out Each Item in 2D List

```py
for row in range(len(grid)):
	for col in range(len(grid[row])):
		# Go through every item of the list by going through every row, 
		# then every column
		print(grid[row][col], end=" ") # Prints item
		
	print() # Very important, adds new line before new row
```

## Nested Loops

**nested loop:** loop inside another loop

```py
# Shows a 5 x 5 right triangle

for row in range(1, 6):
    for col in range(row):
        print("*", end="")
    print()
```

## Tuples

- **tuple:** an immutable sequence datatype that can store various datatypes as items
	- an immutable list
- Format: `tuple_name = (item1, item2, ...)`
- Tuples support read-only operations of lists
	- Indexing for retrieving elements
	- Methods like `index`
	- Built-in funcs. like `len`, `min`, `max`
	- Slicing
	- `in`, `+`, `*` ops.
- Tuples do not support
	- `append`
	- `remove`
	- `insert`
	- `reverse`
	- `sort`

### Advantages of Tuples

- Processing tuples are faster than lists
- **Safe**
- Some ops. in Python require use of tuples

### Conversion between Tuple and List

- `tuple()`: convert to tuple
- `list()`: convert to list
