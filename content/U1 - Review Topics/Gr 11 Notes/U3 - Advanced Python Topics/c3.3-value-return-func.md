# C3.3 - Value-Returning Functions

## Value-Returning Functions

- **value-returning function:** special type of function that returns (a) value(s) back to the program that called it

## Examples of Value-Returning Functions: Built-In

`random.randint(a, b)` where `a` and `b` are inclusive

```py
import random

def main():
	for _ in range(10):
		if random.randint(1, 2) == 1:
			print("heads")
		else:
			print("tails")

if __name__ == "__main__":
	main()
```

## Creating Own Value-Returning Functions

Values are returned directly instead of printed

`return` statement is used

When no value is returned, a value called `None` is returned

```py
def is_even(num):
	return num % 2 == 0

num = int(input("Enter a number: "))

value = is_even(num) # value of function stored in variable

if value:
	print("It's even")
else:
	print("It's odd")
```

### Returning Multiple Values

- **multi-valued assignment:** assigning multiple variables multiple values from a list or tuple
	- occurs when number of variables matches number of values in list
- Multiple values from a function are returned as a tuple
- **tuple:** list datatype where values cannot be changed after initialization

```py
def get_next_2_numbers(num):
	return num + 1, num + 2

n1, n2 = get_next_2_numbers(7)

print(7, n1, n2)
```
