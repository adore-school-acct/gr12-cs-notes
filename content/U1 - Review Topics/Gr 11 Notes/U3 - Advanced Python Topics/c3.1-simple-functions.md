# C3.1 - Simple Functions

## Functions

- **function:** named group of statements that perform a specific task
- Advantages to using Functions
	1. Code Reuse
	2. Simpler Code
	3. Easier Debugging (debug once instead of many times)
	4. Supports Teamwork
- **abstraction:** hide away the little details

## Structure

- **function header:** beginning of a function definition &mdash; defines name and parameters
- **block:** set of statements that belong together as a group

## Example

```py
def chorus():
	'''This function sings the chorus of Old MacDonald had a farm.'''
	print("Ee-igh, ee-igh, oh")
	print()

chorus()
```

**Order of Execution**

1.  Line above `chorus()`?
2. `chorus()`
3. `def chorus():`
4. Line-by-line under `def chorus():`
5. End of `chorus()`

## The `main()` Function

- The main function
- Contains mainline logic
- **mainline logic:** overall logic of program
- `main()` must be called at the bottom

```py
def main():
	chorus()

def chorus():
	'''This function sings the chorus of Old MacDonald had a farm.'''
	print("Ee-igh, ee-igh, oh")
	print()

if __name__ == "__main__":
	main()
```

## Scope

- **scope:** part of a program where a variable may be accessed
- **local variable:** variable that belongs to the function it was created
	- all variables in a function are local
- **global variable:** variable that can be accessed by the entire program
