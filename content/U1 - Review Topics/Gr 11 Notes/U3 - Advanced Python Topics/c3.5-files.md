# C3.5 - Files

## Persistent Data

- **persistent data:** data retained between execution of program
- Data must be stored to a file on the disk in order to be used again

## Opening a File

**General Format**

```py
file_variable = open(filename, mode)
```

- `file_variable`: name of variable that references the file
- `filename`: string specifiying location / name of file
	- by default, Python assumes file is in same directory as program itself
- `mode`: single character string indicating what file is being opened for
	- `'r'` &mdash; reading: opens a file in read-only mode, throws `FileNotFoundError` if file doesn't exist
	- `'w'` &mdash; writing: overwrites content of file; creates a file if it does not exist
	- `'a'` &mdash; appending: appends content to the end of the file; creates a file if it does not exist

## Closing a File

```py
file_variable.close()
```

`close()` function used to close file

No closing = potential data loss / corruption

## Reading a File

### Reading All Contents

Method: `file_variable.read()`

```py
# let f be file

f = open("test.txt", "r")
f_contents = f.read()
f.close()

print(f_contents)
```

### Reading Line-by-Line

Method: `file_variable.readline()`

Supplementary method: `.strip()` 

```py
f = open("test.txt", "r")

line1 = f.readline() # includes newline characters too
line2 = f.readline()
line3 = f.readline()

f.close()

print(line1.strip())
print(line2.strip())
print(line3.strip())
```

#### `string.strip()`

- removes leading and trailing whitespace and newlines
- `string.strip(x)`: `x` used to specify leading and trailing characters to remove in a string

### Loop Line-by-Line

```py
f = open("test.txt", "r")

for line in f:
	print(line.strip())

f.close()
```

## Writing to a File

- Use `w` to overwrite
- Use `a` to append
- Method: `file_variable.write(string)` where `string` is the string written
	- Does not include newlines by default!
	- Does not accept any other datatypes other than a string

```py
f = open("test.txt", "w")

for i in range(1, 11):
	f.write(str(i) + "\n")

f.close()
```
