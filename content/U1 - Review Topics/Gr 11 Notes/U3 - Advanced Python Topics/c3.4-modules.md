# C3.4 - Modules

## Modules

- **module:** Python file that contains a collection of functions that perform related tasks
- **standard library:** functions that perform tasks that programmers commonly need to do
- Must be imported using an `import` statement
- **dot notation:** function's name is preceded by a dot, then its respective module or class
- **modularization:** organizing program into modules
- **namespace**: name to declare the scope of a function / variable
- **menu-driven program:** program driven by a list of options that a user selects

## The `random` module &mdash; Random Numbers

### Example Functions

- `random.randint(a, b)`: returns an integer between `a` and `b` inclusive
- `random.randrange(a, b, c=1)`: returns an integer between `a` (inclusive) and `b` (exclusive) with step value `c` (1 if not given)
	- works very similarly to `range()`
	- or most simply, `random.randrange(x)` (return int. from 0 to `x` (excl.))
- `random.random()`: returns a float between `0.0` (incl.) and `1.0` (excl.)
- `random.uniform(a, b)`:  returns a float between `a` and `b`, inclusive
- `random.choice(seq)`: returns an element from a sequence datatype

### Example Usage

```py
import random

def main():
	# Generate a random number between 1 to 100

	number = random.randint(1, 100) # dot notation
	print("Random number:", number)

if __name__ == "__main__":
	main()
```

### Pseudorandomness

- **pseudorandom number:** numbers that appear random but are really not
- Computers are unable to generate true random numbers
- Random numbers are calculated mathematically using a **seed**
- **seed:** integer value used to calculate next random number
- *Default seed:* the UNIX time of a computer (s. since Jan 1, 1970)

#### Setting a Custom Seed

```py
import random

random.seed(100)

for _ in range(10):
	print(random.randint(1, 100))

'''
The 10 numbers produced will always be the same
'''
```

## The `math` Module

### Example Functions and Constants

**Excluding dot notation**

- `exp(x)`: $e$ raised to the power of `x`
- `sqrt(x)`: square root of `x`
- `log(x, base)`: log `base` of `x`
- `log10(x)`: log 10 of `x`
- `floor(x)`: round `x` down to the nearest integer
- `ceil(x)`: round `x` up to the nearest integer
- `degrees(x)`: convert `x` to degrees
- `radians(x)`: convert `x` to radians
- `sin(x)`: sine of `x`, radians
- `cos(x)`: cosine of `x`, radians
- `tan(x)`: tangent of `x`, radians
- `asin(x)`: inverse sine of `x`, radians
- `acos(x)`: inverse cosine of `x`, radians
- `atan(x)`: inverse tangent of `x`, radians
- `pi`: $\pi$
- `e`: $e$, Euler's number

### Example Usage

```py
import math

def main():
	# Find square root of 49
	print(math.sqrt(49))

if __name__ == "__main__":
	main()
```

## Advanced Importing Techniques

```py
import math
```

creates a new namespace. Must be clear to specify function is from `math`

---

Using `from` to import specific functions

```py
from math import sqrt, pi

print(sqrt(49) * pi)
```

:warning: **EXTREMELY RISKY:** BAD PRACTICE

```py
from math import *

...
```

In above case, you don't know what's being imported and may cause conflicts

## Creating Own Modules

i.e. Create `circle.py` to find `area` and `circumference`

```py
'''
circle.py
'''

from math import pi

def area(radius):
	return pi * radius ** 2

def circumference(radius):
	return 2 * pi * radius
```

```py
'''
main.py
'''
import circle

def main():
	radius = float(input("Enter radius of circle: "))
	A = circle.area(radius)
	C = circle.circumference(radius)

	print("Area:", A)
	print("Circumference:", C)
```

:warning: **IMPORTANT:** Make sure to NEVER execute a function inside of a module; otherwise conflicts will occur
