# C4.x - Tic-Tac-Toe Analysis

## Algorithm

1. You will play in a 3x3 grid pre-drawn that looks like this:
	```
	   |   |  
	---+---+---
	   |   |   
	---+---+---
	   |   |   
	```
	1. (0, 0) is the top-left square
	2. (0, 1) is the top-center square
	3. (0, 2) is the top-right square
	4. (1, 0) is the center-left square
	5. (1, 1) is the true center square
	6. (1, 2) is the center-right square
	7. (2, 0) is the bottom-left square
	8. (2, 1) is the bottom-center square
	9. (2, 2) is the bottom-right square
2. Choose the starting player (Player 1). Other player is Player 2
3. The starting player is to place an `X` in any blank square
4. Player 2 places an `O` in any blank square
5. Repeat steps 3-4 until
	1. grid is full
	2. there are 3 `X`s or `O`s in a row, column, and diagonal
6. Player 1 wins if there are 3 `X`s in a row, column, and diagonal
7. Player 2 wins if there are 3 `O`s in a row, column, and diagonal
8. Game over

### Check Winner

```py
def winner(board):
	# Check rows for winner
    for row in range(3):
        if (board[row][0] == board[row][1] == board[row][2])\
        and (board[row][0] != " "):
            return board[row][0]
	
	# Check columns for winner
	for col in range(3):
        if (board[0][col] == board[1][col] == board[2][col])\ 
        and (board[0][col] != " "):
            return board[0][col]

	# Check diagonal (top-left to bottom-right) for winner
    if (board[0][0] == board[1][1] == board[2][2]) and\ 
    (board[0][0] != " "):
        return board[0][0]
	
	# Check diagonal (top-right to bottom-left) for winner
    if (board[0][2] == board[1][1] == board[2][0]) and\ 
    (board[0][2] != " "):
        return board[0][2]
```

- Loops through every row / column index
- 3 times for 3 rows and 3 columns
- No winner returns empty string
- No winner if item in square is blank

### Make User Move

```py
def make_user_move(board):
    valid_move = False
    while not valid_move:
        row = int(input("What row would you like to move to (0-2):"))
        col = int(input("What col would you like to move to (0-2):"))
        if (0 <= row <= 2) and (0 <= col <= 2) and (board[row][col] == " "):
            board[row][col] = 'X'
            valid_move = True
        else:
            print ("Sorry, invalid square. Please try again!\n"
```

- Purpose of decision structure: Make sure user's move is valid
- Places an `X` in the appropriate square

### Make Computer Move

```py
import random
# ...

def make_computer_move(board):
	# Step I: Keep track of empty squares
	empty_squares = []

	for row in range(3):
		for col in range(3):
			if board[row][col] == " ":
				empty_squares.append((row, col))
	
	# STEP II: Pick coordinate randomly and place 'O' on board

	comp_row, comp_col = random.choice(empty_squares)
	board[comp_row][comp_col] = 'O'
```

### Main Function

```py
def main():
	free_cells = 9
	users_turn = True
	ttt_board = [[' ', ' ', ' '],
				 [' ', ' ', ' '],
				 [' ', ' ', ' ']]
				
	while not winner(ttt_board) and (free_cells > 0):
		display_board(ttt_board)

		if users_turn:
			make_user_move(ttt_board)
			users_turn = not users_turn
		else:
			make_computer_move(ttt_board)
			users_turn = not users_turn
			
		free_cells -= 1

	display_board(ttt_board)

	if (winner(ttt_board) == 'X'):
		print("Y O U  W O N !")
	elif (winner(ttt_board) == 'O'):
		print("I   W O N !")
	else:
		print("S T A L E M A T E !")
	print("\n*** GAME OVER ***\n")

# Start game!
main()
```

- Keep track of free cells to determine if there are cells left for the game to not be over
- `while` loop will loop for game moves while there ain't a winner and there are free squares left
- `not winner(ttt_board) == True` when `winner(ttt_board) == ""`

**User's turn**

- User prompted to make a move
- User's `X` is placed
- Turn changed to computer's

**Computer's turn**

- Computer makes move
- Computer's `O` is placed
- Turn changed to user's
