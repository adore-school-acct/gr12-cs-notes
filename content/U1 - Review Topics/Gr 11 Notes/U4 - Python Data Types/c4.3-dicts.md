# C4.3 - Dictionaries

## Dictionaries

- **dictionary:** mutable sequence datatype storing pairs with a key and its corresponding value
	- keys must be immutable
- **hashing / mapping:** accessing data via a custom index
- `KeyError`: error when trying to access value of key not in dictionary

Format

```
dict = {key1: value1, key2: value2, ..., keyn: valuen}
```

Example

```py
capital_of = {"Germany": "Berlin", "Russia": "Moscow", "Italy": "Rome", "Japan": "Tokyo"}
```

## Indexing and Using `in`

`dict.values()`: get a list of all the values (not keys) in a dictionary

```py
capital_of = {"Germany": "Berlin", "Russia": "Moscow", "Italy": "Rome", "Japan": "Tokyo"}

# Look for key and print its value

if "Germany" in capital_of:
	print(capital_of["Germany"])
else:
	print("I thought Germany was a country.")

# Loop over keys in dictionaries

for country in capital_of:
	print(country)

# With values

if "Moscow" in capital_of.values():
	print("Interesting...")

for capital in capital_of.values():
	print(capital)
```

## Changing Values in Dictionary

- Format: `dict[key] = new_value`
- A new key-value pair will be created if the key doesn't exist
- `del` can be used to remove a pair

```py
capital_of = {"Germany": "Berlin", "Russia": "Moscow", "Italy": "Rome", "Japan": "Tokyo"}

# Add a value
capital_of["Canada"] = "Toronto"
print(capital_of)
# Change a value
capital_of["Canada"] = "Ottawa"
print(capital_of)
# Remove a value
del capital_of["Canada"]
print(capital_of)
```

## Dictionary Methods

Format: `dict.method(...)`

|Method|Description|
|-|-|
|`has_key(key)`|Does dictionary have key stored in `key`?|
|`keys()`|Return list of keys|
|`values()`|Return list of values|
|`get(key, default)`|Get the value corresponding to `key`, else return `default`|
|`clear()`|Remove all items in dictionary|
|`update(dict2)`|Add keys and values of `dict2` into `dict`|
|`del dict[key]`|Delete a key-value pair with `key`|
|`pop(key)`|Delete a key-value pair with `key`|
