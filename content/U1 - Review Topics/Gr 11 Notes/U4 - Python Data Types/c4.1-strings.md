# C4.1 - Strings

## What is a String?

- **string:** sequence datatype that stores a sequence of characters
	- strings are immutable
	- strings can only be replaced, not changed
- **sequence datatype:** object that contains multiple items of data
- **immutable object:** object itself cannot be changed after creation

## Indexing

- **index:** the location of an item in a sequence data type
	- starts at 0, and counts up by 1 (L to R)
	- starts at -1, and counts down by 1 (R to L)
- `IndexError`: error when index outside of sequence datatype's range is trying to be accessed

|B|e|a|r|i|n|g|
|-|-|-|-|-|-|-|
|0|1|2|3|4|5|6|
|-7|-6|-5|-4|-3|-2|-1|

Print "Bg" from "Bearing"

```py
text = "Bearing"
print(text[0] + text[-1])
```

IndexError

```py
text = "Bearing"
print(text[21])
```

**Immutability in action**

```py
text = "Stolen"
text[2] = 'a'
text[-2] = 'o'
print(text)

# Will return error
```

## Slicing

- **slice:** span of items taken from a sequence
	- a.k.a. **substring**

Slicing Format

```
string[start:stop]
string[start:stop:step]
```

- `start`: index to start from (inclusive)
	- if blank, starts at beginning
- `stop`: index to end at (exclusive)
	- if blank, goes to end
	- can be set to index beyond list &rarr; goes to end
- `step`: skip number, count index by...
	- i.e. `2` skips every other index
	- negative indices counts backwards

#### Reverse a String

`string[::-1]`

```py
text = "!dnalsi eht dniF"
print(text[::-1])
```

##  `in`

Use `in` operator to check if substring in string

```py
text = "fast car"

if "fast" in text:
	print("zoooom")
else:
	print("slow")
```

Or use `in` to loop over characters

```py
text = "fast car"

for ch in text:
	print(ch)
```

## String Methods

Format: `'string'.method(...)`

### Testing Methods

**testing methods:** tests whether a certain condition is met in a string &rarr; returns boolean

|Method|Description|
|-|-|
|`isalnum()`|Only letters and numbers? Not blank?|
|`isalpha()`|Only letters? N.B.?|
|`isdigit()`|Only numbers? N.B.?|
|`islower()`|All lowercase? Not empty?|
|`isspace()`|Only whitespace? N.E.?|
|`isupper()`|All uppercase? N.E.?|

### Modification Methods

**modification methods:** methods that modifies a string and returns it

|Method|Description|
|-|-|
|`lower()`|Converts to lowercase|
|`upper()`|Converts to uppercase|
|`capitalize()`|Capitalizes first letter. Rest are lowercased.|
|`title()`|Capitalizes first letter of each word|
|`swapcase()`|Returns lowercase to uppercase and vice versa|
|`strip(ch=[optional])`|Removes leading and trailing characters in `ch` or whitespace/newlines by default|
|`lstrip(ch=[opt])`|Removes leading characters. Like `strip()`|
|`rstrip(ch=[opt])`|Removes trailing characters. Like `strip()`|

### Search and Replace Methods

- **search methods:** method that searches for item in string
- **replace methods:** method that replaces the found substring in a string

|Method|Description|
|-|-|
|`endswith(substr)`|Does string end with `substr`?|
|`startswith(substr)`|Does string start with `substr`?|
|`find(substr)`|What is the index of the first occurrence of `substr`? Return -1 if not found|
|`index(substr)`|Like `find` except it throws `ValueError` if `substr` not found|
|`replace(old, new)`|Replace all occurrences of substr. `old` with substr. `new`|
