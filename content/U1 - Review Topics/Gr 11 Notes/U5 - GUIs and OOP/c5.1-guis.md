# C5.1 - Graphical User Interfaces & OOP

## About GUIs

- **command line interface (CLI):** interface where user gives commands via text prompts to the system
	- only way back in MS-DOS, 1980s
	- program dictates how you interact w/ it
	- i.e. area program; must enter length before width
- **graphical user interface (GUI):** interface where user interacts using a mouse to point and click on graphic elements on screen
	- GUIs are *event-driven*
	- **event-driven:** user dictates how events take place in program

## `tkinter` module

- `tkinter` is the default GUI interface for Python
	- short for "Tk interface"
- Tk is "powerful" GUI library that many other programming langs. use
- GUI program presents window w/ various graphical widgets that user can interact w/ and view

### Widgets

Accessible via `tkinter.WidgetName`

|Widget|Description|
|-|-|
|`Button`|Causes action to occur when clicked|
|`Canvas`|Rectangular area to display graphics|
|`Checkbutton`|Checkbox in "on" or "off" position|
|`Entry`|Textbox where user may type in single line of input|
|`Frame`|Container that can hold other widgets|
|`Label`|Area that displays a line of text or image|
|`Listbox`|List from which the user may select an item|
|`Menu`|List of menu choices displayed when user clicks on a `Menubutton`|
|`Menubutton`|Menu that is displayed on screen and may be clicked by user|
|`Radiobutton`|Circular widget can be either be selected or deselected. Usually appear in groups and allow user to select one of several options.|
|`Scrollbar`|Can be used w/ some other widgets to provide scrolling ability|
|`Text`|Area where user can enter multiple lines of text input|
|`Toplevel`|Container that is displayed in its own window|

## Basic GUI Implementation

```py
import tkinter as tk

def main():
	# Create main window widget
	main_window = tk.Tk()
	# Enter tkinter main loop
	tk.mainloop() # buggy

if __name__ == "__main__":
	main()
```

- `Tk` is the **root widget**
	- houses all of GUI components
	- main window of GUI
- `tk.mainloop()`
	- runs the GUI
	- infinite loop that stops when program is closed
	- *experiences:* may be buggy
		- alternative: `main_window.mainloop()`
		- if `tk.mainloop()` does not work


## Basic Window Tricks

let `window = tk.Tk()`

- `window.geomtery("widthxheight")`
	- change the default window size
	- replace `width` and `height` with the desired width and height in pixels
- `window.title("title")` 
	- change the title shown in the window (top bar above content)
	- replace `title` in quotes with the desired title

## Object-Oriented Programming

- `class`: defines an object in Python
	- **object:** a datatype that encompasses related variables and their related functions
- `__init__` function: initializes the components of a function
- `self`: used to make a variable or data belong to the entire class rather than just the function (scope in class)
- **object-oriented programming (OOP):** programming by using objects

### Basic GUI Implementation Using OOP

- Common practice to write GUI within `__init__` function of a class
- Most programmers prefer OOP for GUIs apparently

```py
import tkinter as tk

class MyGUI:
	def __init__(self):
		# Create main window widget
		self.main_win = tk.Tk()
		# Enter main loop (I prefer doing this outside of __init__)
		tk.mainloop()

# Create instance of MyGUI class
if __name__ == "__main__":
	my_gui = MyGUI()
```

## Labels and Packing

- `Label`: widget used to display text on screen
- parameters
	- first argument: reference to root widget (either `Tk`, `Frame`, or `Toplevel`)
	- `text`: text to display (string)
	- `image`: image to display (`tkinter.PhotoImage` or `PIL.ImageTk.PhotoImage`)
	- `textvariable`: shows value of set `tk.StringVar()` &rarr; [[c5.2-gui-input]]
- **`pack()` method:** determines where widget should be placed and makes it visible on window
	- more than one widget? appear stacked on top of each other
		- in order of which widget was "packed" first (top to bottom)
		- even when parameters are changed
	- parameter `side`: side where widget should be displayed
		- options: `"left"`, `"right"`, `"top"`, `"bottom"`

```py
import tkinter as tk

class MyGUI:
	def __init__(self):
		# Create main window
		self.win = tk.Tk()
		# Create 2 labels
		self.label1 = tk.Label(self.win, text="Hello World")
		self.label2 = tk.Label(self.win, text="Hello Again")
		# Call Label widget's pack method
		self.label1.pack()
		self.label2.pack()

def main():
	my_gui = MyGUI()
	tk.mainloop()

if __name__ == "__main__":
	main()
```

To pack widgets side by side, change `pack` methods

```py
# ... existing code
self.label1.pack(side="left")
self.label2.pack(side="left")
# existing code ...

'''
label1 will appear to the left of label2
order still follows first packed
'''
```

## Organizing w/ Frames

- `Frame`: container that can hold other widgets
- useful for arranging items in different ways on same window
- root widget of element must be a frame to belong to a frame

*Basic Implementation*

```py
import tkinter as tk

class MyGUI:
	def __init__(self):
		# Main window
		self.win = tk.Tk()
		# 2 frames
		self.top_frame = tk.Frame(self.win)
		self.bottom_frame = tk.Frame(self.win)
		# 3 labels for top frame
		self.label1 = tk.Label(self.top_frame, text="Eng")
		self.label2 = tk.Label(self.top_frame, text="Popkiewicz")
		self.label3 = tk.Label(self.top_frame, text="Jones")
		# Pack labels on top of each other
		self.label1.pack(side="top")
		self.label2.pack(side="top")
		self.label3.pack(side="top")
		# 3 labels for bottom frame
		self.label4 = tk.Label(self.top_frame, text="Eng")
		self.label5 = tk.Label(self.top_frame, text="Popkiewicz")
		self.label6 = tk.Label(self.top_frame, text="Jones")
		# Pack labels beside each other
		self.label4.pack(side="left")
		self.label5.pack(side="left")
		self.label6.pack(side="left")
		# Pack the frames
		self.top_frame.pack()
		self.bottom_frame.pack()

if __name__ == "__main__":
	my_gui = MyGUI()
	tk.mainloop() # enter main loop
```
