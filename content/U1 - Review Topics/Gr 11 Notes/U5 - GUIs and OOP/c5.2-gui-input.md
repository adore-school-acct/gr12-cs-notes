# C5.2 - User Input in GUIs

## Dialog Boxes

- in module `tkinter.messagebox`
- import using `from tkinter import messagebox`
- `messagebox.showinfo(title, message)`
	- show a pop up / dialog box with an info sign ℹ
	- gives an "OK" button to close
	- `title`: title in dialog box (top bar)
	- `message`: string displayed in content area  of dialog box
- `messagebox.showwarning(title, message)`
	- like `showinfo` but it shows a warning sign instead ⚠
- `messagebox.showerror(title, message)`
	- like `showinfo` but it shows an error sign instead ❌
- `messagebox.askquestion(title, message, type)`
	- show a pop up / dialog box with a question sign ❔
	- has a return value based on user input
	- give user options, buttons based on `type`
		- `messagebox.YESNO` (default)
			- buttons and return values: "Yes" (`True`), "No" (`False`)
			- alternative func: `messagebox.askyesno(title, message)`
		- view [Python docs](https://docs.python.org/3/library/tkinter.messagebox.html) for more

## Buttons

- `Button`: widget that user can click for action to take place
- **event handler:** function that executes when user clicks button
- parameters
	- first argument: root widget reference
	- `text`: text to show on button
	- `command`: event handler
		- note that function is placed without parantheses
		- otherwise, function will be called prematurely
- `tk.Tk.quit()` or `main_window.quit()`: quit the GUI program

### Implementation

```py
import tkinter as tk
from tkinter import messagebox as msg

class MyGUI:
	def __init__(self):
		# Main window
		self.win = tk.Tk()
		# Button that executes do_something when clicked
		self.button = tk.Button(self.win, text="Click Me!", command=self.do_something)
		# Pack button
		self.button.pack()
		
	def do_something(self):
		msg.showinfo("Response", "Thanks for clicking the button.")

if __name__ == "__main__":
	my_gui = MyGUI()
	tk.mainloop()
```

## Entry Widgets

- `Entry`: rectangular area that user can type text into
	- `width` parameter: width of textbox (how many `0` characters?)
- `get()` method: get data typed into entry widget
	- format: `Entry.get()`
- **dynamic display:** elements on display update based on appropriate events
- `StringVar`: tkinter object that stores strings for widgets to display data
	- `Label` has parameter `textvariable` to assign a `StringVar` to
	- `get()`: get value stored in var.
	- `set()` method: set the `StringVar` to the desired string value

### Kilometer to Mile Converter

```py
import tkinter as tk

class KiloConverterGUI:
	def __init__(self):
		# Main window
		self.mw = tk.Tk()
		# 3 frames
		self.top = tk.Frame()
		self.mid = tk.Frame()
		self.bot = tk.Frame()
		# Widgets for top frame
		self.prompt_label = tk.Label(self.top, text="Distance in km:")
		self.kilo_entry = tk.Entry(self.top, width=10)
		# Pack top frame widgets
		self.prompt_label.pack(side="left")
		self.kilo_entry.pack(side="left")
		# Widgets for middle frame
		self.descr_label = tk.Label(self.mid, text="Distance in miles:")
		self.value = tk.StringVar() # conversion to miles
		self.miles_label = tk.Label(self.mid, textvariable=self.value)
		# Pack middle frame widgets
		self.descr_label.pack(side="left")
		self.miles_label.pack(side="left")
		# Create buttons for bottom frame
		self.calc_btn = tk.Button(self.bot, text="Convert", command=self.convert)
		self.quit_btn = tk.Button(self.bot, text="Quit", command=self.mw.quit)
		# Pack buttons
		self.calc_btn.pack(side="left")
		self.quit_btn.pack(side="left")
		# Pack frames
		self.top.pack()
		self.mid.pack()
		self.bot.pack()
		
	def convert(self):
		# Get value from kilo_entry
		kilo = float(self.kilo_entry.get())
		# Convert km to mi
		miles = kilo * 0.6214
		# Display value on GUI
		self.value.set(miles)

if __name__ == "__main__":
	kilo_conv = KiloConverterGUI()
	tk.mainloop()
```
