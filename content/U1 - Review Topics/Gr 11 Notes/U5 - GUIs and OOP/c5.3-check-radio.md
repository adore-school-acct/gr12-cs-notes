# C5.3 - Checkbutton and Radiobutton Widgets

## Radiobutton

- `Radiobutton`: circular widget can be either be selected or deselected
	- usually appear in groups and allow user to select one of several options.
	- parameters
		- `variable`: variable associated w/ radio button (option selected)
		- `text`: text associated w/ radio button
		- `value`: value associated w/ radio button (will write into `variable` when selected)
		- `command`: event handler
			- radio buttons can execute functions when clicked
- `IntVar`: a tkinter object to store integers
	- used to store radio button selection
	- `get()`: get value stored in var.
	- `set()`: set value of var.

```py
import tkinter as tk
import tkinter.messagebox as msg

class MyGUI:
	def __init__(self):
		# Main window
		self.mw = tk.Tk()
		# 2 frames for radio buttons and reg. buttons
		self.top = tk.Frame(self.mw)
		self.bot = tk.Frame(self.mw)
		# Int var for radio buttons
		self.radio_var = tk.IntVar()
		self.radio_var.set(1) # default value
		# Radiobutton widgets in top frame
		self.rb1 = tk.Radiobutton(self.top, text="Option 1", variable=self.radio_var, value=1)
		self.rb2 = tk.Radiobutton(self.top, text="Option 2", variable=self.radio_var, value=2)
		self.rb3 = tk.Radiobutton(self.top, text="Option 3", variable=self.radio_var, value=3)
		# Pack radiobuttons
		self.rb1.pack()
		self.rb2.pack()
		self.rb3.pack()
		# OK Button
		self.ok_button = tk.Button(self.bot, text="OK", command=self.show_choice)
		self.ok_button.pack(side="left")
		# Pack frames
		self.top.pack()
		self.bot.pack()

	def show_choice(self):
		option = str(self.radio_var.get())
		msg.showinfo("Selection", "You selected option " + option)

if __name__ == "__main__":
	my_gui = MyGUI()
	tk.mainloop()
```

- 3 radio buttons with unique values of 1, 2, and 3
- Initial setting causes one radio button to be selected by default
- `Radiobutton` selected depending on its associated `IntVar`

## Checkbutton

- `Checkbutton`: Checkbox in "on" or "off" position
	- allows for multiple selections at same time
	- parameters
		- `variable`: variable associated w/ checkbox (option selected)
			- each `Checkbutton` has its own `variable`
		- `text`: text associated w/ checkbox
		- `value`: value associated w/ checkbox (will write into `variable` when selected)
			- default: `0` for unchecked
			- `1` for checked (def.)
		- `command`: event handler
- allows for multiple choices

```py
import tkinter as tk
import tkinter.messagebox as msg

class MyGUI:
	def __init__(self):
		# Main window
		self.mw = tk.Tk()
		# 2 frames for radio buttons and reg. buttons
		self.top = tk.Frame(self.mw)
		self.bot = tk.Frame(self.mw)
		# Int vars for checkboxes
		self.cb_var1 = tk.IntVar()
		self.cb_var2 = tk.IntVar()
		self.cb_var3 = tk.IntVar()
		# Checkbutton widgets in top frame
		self.cb1 = tk.Checkbutton(self.top, text="Option 1", variable=self.cb_var1)
		self.cb2 = tk.Checkbutton(self.top, text="Option 2", variable=self.cb_var2)
		self.cb3 = tk.Checkbutton(self.top, text="Option 3", variable=self.cb_var3)
		# Pack checkbuttons
		self.cb1.pack()
		self.cb2.pack()
		self.cb3.pack()
		# OK Button
		self.ok_button = tk.Button(self.bot, text="OK", command=self.show_choice)
		self.ok_button.pack(side="left")
		# Pack frames
		self.top.pack()
		self.bot.pack()

	def show_choice(self):
		# Message string
		self.message = "You selected:\n"
		# Determine selected checkboxes and build message string accordingly
		if self.cb_var1.get() == 1:
			self.message += "1\n"
		if self.cb_var2.get() == 1:
			self.message += "2\n"
		if self.cb_var3.get() == 1:
			self.message += "3\n"
		# Display message
		msg.showinfo("Selection", self.message)

if __name__ == "__main__":
	my_gui = MyGUI()
	tk.mainloop()
```
