# C2.3 - Decision Structures

## Types of Structures (incl. *sequence structure*)

- **sequence structure:** set of statements that execute in the order they appear, from top to bottom
- **decision structure:** set of statements that are executed only if a certain condition is True, otherwise skipped entirely

## Boolean Expressions and Relational Operators

- **boolean expression:** condition that evaluates to True or False
- **relational operator:** operator that compares two values
  - look at file to see symbol w/o ligature
  - `>`: greater than
  - `<`: less than
  - `>=`: greater than or equal to
  - `<=`: less than or equal to
  - `==`: equality (equal to)
  - `!=`: not equal to

## Logical Operator, Binary, and Unary

- **binary operator:** operator that needs two expressions
- **unary operator:** operator that needs only one expression
- **logical operator:** compares two boolean expressions
  - `and`: returns True if both expressions are true (binary)
  - `or`: returns True if one of the expressions are true (binary)
  - `not`: returns True if the given expression is False (unary)

## If, Elif, and Else Statements

- **`if` statement:** implements a decision structure, one decision
- **`if...else` statement:** decision structure w/ one decision and a fallback decision
- **`if...elif...else` statement:** decision structure w/ many decisions and a fallback decision (if there is an `else` block)

*Format*

```py
# if

if condition:
    statement

# if ... else

if condition:
    statement
else:
    statement

# if ... elif ... else

if condition:
    statement
elif condition:
    statement
...
else:
    statement
```

*Example*

```py
'''
header
'''

X = int(input("Enter int: "))

if X == 0 or X == 21:
    print(0)
elif X > 0:
    print(1)
else:
    print(-1)
```

For each block, the first statement / block to return `True` will be executed, while the rest will be skipped

### Nested Decision Structures (use `elif` instead)

Example

``` py
if condition:
    task
    else:
        if condition:
            task
            else:
                if condition:
                    task
```
