# C2.4 - Repetition Structures

## Repetition Structure

**repetition structure:** (a.k.a.) loop, causes Python to repeat a statement / set of statements more than once

- alt word for "repeat": "iterate"
- **iteration:** each time the body of a loop is repeated
- *Categories of Loops*
  - condition-controlled
  - counter-controlled

## Condition-Controlled Loop

**condition-controlled loop:** loop that causes a (set of) statements to repeat as long as a condition is True

- `while` statement used
- condition is a Boolean expression
- if condition is True, body of loop executes once
- condition checked again
- repeats until condition yields false
- **pre-test loop:** loop that tests condition before executing

```py
while condition:
    statements
```

```py
# Example of loop that counts from 1 to 10

num = 1

while num <= 10:
    print(num)
    num += 1
```

**infinite loop:** loop that occurs when condition never becomes False

Important that condition in `while` loop eventually yields `False`

*Infinite loop example*

```py
health = 10
damage = 3

while health != 0:
    print("Health: %d" % health)
    print("You take %d damage" % damage)
    health -= damage

'''
Values of health per iteration
It. 1: 10
It. 2: 7
It. 3: 4
It. 4: 1
It. 5: -1

Value never reaches zero
'''
```

Bugfix of above: Replace `health != 0` with `health > 0`

## Counter-Controlled Loop

**counter-controlled loop:** loop that repeats an exact number of times

- `for` statement used
- works with sequence data types
- **sequence data type**
  - *lists:* sequence data types with data enclosed in square brackets
  - tuples
  - strings
- **loop control variable:** variable that changes its value for each iteration of the `for` loop

### range()

`range()`: function that automatically creates a *list*

- `range(stop)`: creates a list from 0 (inclusive) up to `stop` (exclusive), counting up by 1
    - format: `[0, 1, ..., stop - 1]`
    - i.e. `range(6) == [0, 1, 2, 3, 4, 5]`
- `range(start, stop)`: creates a list from `start` (incl.) up to `stop` (excl.), counting up by 1
    - format: `[start, start + 1, ..., stop - 1]`
    - i.e. `range(1, 6) == [1, 2, 3, 4, 5]`
- `range(start, stop, step)`: creates a list from `start` (incl.) up to `stop` (excl.), counting up by `step`
    - if `step` is negative, `range()` counts down
    - format: `[start, start + step, ...]` until next number > `stop`
    - i.e. fwd: `range(2, 11, 2) == [2, 4, 6, 8, 10]`
    - i.e. bwd: `range(5, 0, -1) == [5, 4, 3, 2, 1]`
- **step value:** the third argument passed in the `range()` function

## `break` and `continue`

- `break`: terminates a loop early before it is finished
- `continue`: skips the current iteration of a loop from finishing
- above statements should be used sparingly, don't use them unless you need to

*Examples of `break` and `continue`*

```py
# Prematurely exits at 5

for num in range(1, 11):
    if num == 5:
        print("five")
        break
    
    print(num)

# Skips the number 5

for num in range(1, 11):
    if num == 5:
        print("five")
        continue
    
    print(num)

'''
Output:
1
2
3
4
five
1
2
3
4
five
6
7
8
9
10
'''
```

## Sentinels

**sentinel:** special value used to mark the end of a loop / sequence of terms

```py
total_marks = 0

mark = int(input("Enter a mark, or -1 to end: "))

while mark != -1:
	if mark != -1:
	    total_marks += mark
		
    mark = int(input("Enter a mark or -1 to end: "))

print("Sum of marks: %d" % total_marks)
```

## Nested Loops

**nested loop:** loop inside another loop

```py
# Shows a 5 x 5 right triangle

for row in range(1, 6):
    for col in range(row):
        print("*", end="")
    print()
```

## Augmented Operators

**augmented operator:** short-hand operator that allows you to add/sub/mult./div a value to a variable

|Augmented Operator|Format|Equivalent to|
|-|-|-|
|`+=`|`a += b`|`a = a + b`|
|`-=`|`a -= b`|`a = a - b`|
|`*=`|`a *= b`|`a = a * b`|
|`/=`|`a /= b`|`a = a / b`|
|`//=`|`a //= b`|`a = a // b`|

## Choosing a Loop

- `for` loop: use when number of repetitions is (precisely) known before the loop
- `while` loop: use when don't know how many times loop needs to repeat, and where loop may not execute at all if cond. is False
