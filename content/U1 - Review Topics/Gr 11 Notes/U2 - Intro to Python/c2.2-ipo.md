# C2.2 - Input, Processing, Output

## Get Input

**`input()` function:** Python built-in function to collect user input

*Format*

```py
variable = input(prompt)
```

where `prompt` is an optional string displayed on-screen before user inputs something

*Example*

```py
name = input("What is your name? ")
print("Name:", name)

"""
---SAMPLE OUTPUT---
What is your name? Bob
Name: Bob
"""
```

## Data Type Conversions

- `int()`: convert to integer
- `float()`: convert to float
- `str()`: convert to string
- `type()`: check type of a variable

``` py
x = str(7)
y = int(x)
z = float("8.9")

print(type(x))
print(type(y))
print(type(z))

"""
---OUTPUT---
<class 'str'>
<class 'int'>
<class 'float'>
"""
```

## Escape Characters

**escape character:** character preceded w/ backslash (`\`), treated with special formatting

- `\n`: newline
- `\t`: tab
- `\'`: single quote
- `\"`: double quote
- `\\`: single backslash

*Example*

```py
print("Mrs.\nPopkiewicz says \"You will get 90\\100\"\tI\'m hoping that she\'s right!")

"""
---OUTPUT---
Mrs.
Popkiewicz says "You will get 90\100"	I'm hoping that she's right!
"""
```

## String Concatenation

- **string concatenation:** to append / join one string to another
  - `+` used as operator for concatenation
  - `*` used as operator to repeat a string
    - format: `string * int`
- **operator overloading:** when same operator can be used for more than one task

```py
shape = "flat"
print("The Earth is " + shape)
print(shape * 3)

"""
---OUTPUT---
The Earth is flat
flatflatflat
"""
```

## Formatted Printing

- **formatting specifier:** part of a string that specifies what data should be shown and how much space should be given
  - **string format operator:** `%`
- **field width:** minimum and total \# of spaces used to display a value

*Formatting Specifiers and Format*

(stuff) means stuff is optional

let `x` be field width, `y` be \# of decimal places shown

- `%(x)s`: display a string
- `%(x)d`: display an int.
- `%(x)(.y)f`: display a float

If `x` is left blank, Python will give only the field width a value needs

If `y` is left blank, the amount of decimal places that a number has will be shown

*Format of usage*

```py
one_specifier = "... %(x)(.y)[x/d/f] ..." % value
many_specifiers = "... %(x)(.y)[x/d/f] ... %(x)(.y)[x/d/f] ... etc." % (value1, value2, ...) 
```

*Example*

```py
my_value = 1.23456789

print("The value is:%7.2f" % my_value)
print()

# *****

player1 = "Mrs. Popkiewicz" 
player2 = "Mr. Eng"

score1 = 1000000
score2 = 3

print("PLAYER          SCORE")
print("%15s %10d" % (player1, score1))
print("%15s %10d" % (player2, score2))

"""
---OUTPUT---
The value is:   1.23

PLAYER          SCORE          
Mrs. Popkiewicz    1000000
        Mr. Eng          3
"""
```
