# C2.1 - Intro to Python

## Mu and IDEs

- **Integrated Development Environment (IDE):** a program that combines a text editor and access to the interpreter / compiler
- **Mu:** the preferred IDE of this class
- Python file extension: `.py`

## Displaying Output + Keyword

- **keyword:** an important / reserved word that has special meaning to a program
- **function:** a piece of prewritten code that performs an operation and returns a value back to the program
- **`print()` function:** keyword that tells Python to print some data
- **string:** *datatype* that is a sequence of characters (letters, numbers, symbols)

*Example Output Program*

```py
print("Game over!")

"""
--OUTPUT--
Game over!
"""
```

Data to be outputted in `print()` must be enclosed in parantheses

Strings can either be enclosed in single-quotes or double-quotes

Data in `print()` can be seperated by commas, which seperates them by a space in the output

```py
print('single-quote')
print("double-quote")
print("a", "b", 12)

"""
--OUTPUT--
single-quote
double-quote
a b 12
"""
```

### Quotes in Strings

Double quotes can be enclosed with `"` and single quotes can be enclosed with `'`

```py
print('"The moon landing was fake," said Bob, head of the American Conspiracy Society') # valid
print("Bob's dog was taken away after Bob said something 'controversial'") # valid

"""
--OUTPUT--
"The moon landing was fake," said Bob, head of the American Conspiracy Society
Bob's dog was taken away after Bob said something 'controversial'
"""
```

### Triple-Quoted Strings (Multiline Strings)

**triple-quoted string:** a string that allows both single and double-quotes, as well as multiple lines, enclosed in triple quotes: `"""` or `'''`

```py
print('''"Obey me," said Nigeria's prince.''')
print("""<!'"'!>""")
print('''
            .''
  ._.-.___.' (`\\
 //(        ( `'
'/ )\\ ).__. ) 
' <' `\\ ._/'\\
   `   \\     \\
''')

"""
--OUTPUT--
"Obey me," said Nigeria's prince.
<!'"'!>
[The ASCII Image of the horse]
"""
```

## Code Comments

- **comment:** notes of explanation that document lines or sections of a program 
  - Part of program
  - Ignored by interpreter
  - Intended for people who will read / review / modify your code
- **end-of-line comment:** comment after the end of a line
- **full-line comment:** comment that takes up its own line

```py
# Print explanation of why the Earth is flat
print("The earth is flat because everything is upright")
print("Round Earth images are Photoshopped") # Breaks 'reasonable doubt'
```

*Text faded in gray above are comments*

## Header Docstrings

- **docstring:** a triple-quoted string used to document parts of code, that can be interpreted into online help using *pydoc*
- **header comment:** includes information about a program and its author &mdash; *MUST CONTAIN:*
  - Name / Author
  - Date
  - Description &rarr; what the program does or its purpose

*Example*

```py
"""
Name: Adore S.
Date: 2025 Feb 25
Description: Prints out 'This is good'
"""

# Print statement
print("This is good")
```

## Variables

- **variable:** name that represents a value stored in the computer's memory
- **assignment statement:** a section of code used to set a variable's value
  - **assignment operator:** `=`
  - variable name must be at left of operator
  - value to be set must be at right of operator

*Defining a variable named* `high_score`

```py
high_score = 950
```

### Variable Naming Rules

1. Cannot use Python keyword, i.e. `print` or `if`
2. First char. must be a letter or an underscore (`_`)
3. After first char., letters, digits and underscores may be used
4. Blank spaces or special symbols (i.e. $, %, *, etc.) cannot be used
5. Variables are *case-sensitive*: `High_Score` &ne; `high_score`

### Good Variable Naming Conventions and Styles

1. Characters must be lower/uppercase letters
2. After the 1st char., numbers and _ can be used
3. No special characters
4. Names should be descriptive

- `pot_hole_case`: words are seperated using underscores
- `camelCase`: words are put together and the first letter of each word after the first is capitalized

### Re-assigning Variables

Values of variables can change

*NOTE:* Old value is still stored in memory but no longer referenced. Python will eventually free the memory if no longer used.

```py
x = 950
print(x)
x = 1234
print(x)

"""
--OUTPUT--
950
1234
"""
```

## Syntax

**syntax:** the "grammar" of a programming language

**syntax error:** when there is a problem with the program's grammar

## Dynamic vs. Static Typing

- **dynamic typing:** interpreter automatically figures out datatype of variable
- **static typing:** programmer must define datatype of variable and type cannot change

## Data Types

**data type:** a category of specific values

***4 Basic Data Types of Python***

- **integers, `int`:** whole numbers and negative whole numbers (i.e. -3, 1, 4)
- **floating-point numbers, `float`:** decimal / real numbers (i.e. 3.14, 0.0, -0.5)
- **strings, `str`:** text (i.e. "*Hello, world!*")
- **booleans, `bool`:** the values `True` or `False` (*added*)

## Basic Calculations

BEDMAS applies

- **operator:** a symbol that tells Python to do a specific task
- **mathematical operator:** operator that performs calculations
- **precedence:** rules followed in operations, BEDMAS
    1. `()` Brackets
    2. Exponents
    3. Division, Multiplication, Modulo (L &rarr; R)
    4. Addition, Subtraction (L &rarr; R)

---

- `+`: addition
- `-`: subtraction
- `*`: multiplication
- `/`: division (always returns a float)
- `**`: exponents
- `%`: modulo (return remainder of division)
- `//`: floor division (returns int.)
