# C1.1 - Computer Systems and Hardware Model

## Software

- Consists of computer programs in 0's and 1's that tell what a computer to do (instructions)
- All data in computer stored as binary code
- Characters and letters are stored by following ASCII or Unicode

### Types of Software

1. Operating System Software
   1. i.e. Windows, Mac, Ubuntu Linux, Debian Linux, etc.
2. Application Software
3. Development Software &mdash; Software Development Tools
   1. i.e. Python, C, Java (programming languages)
   2. IDEs and code editors fall under applications

## Hardware

- Consists of physical devices that are touchable
- a.k.a. components
- Hardware and their electrical circuits actually do all the work of the software

### Categories of Hardware &mdash; The Hardware Model

- **CPU (Central Processing Unit):** "Brain" of the computer
  - Interprets software instructions (0s and 1s)
  - Controls other hardware model components
- **Internal Memory:** Used to store data and instructions
  - **RAM (Random Access Memory):** Used to temporarily store data and instructions that are currently being executed by CPU; volatile
  - **ROM (Read-Only Memory):** Used by manufacturer of computer to store data and instructions specific to the computer's system; non-volatile
    - The data is permanently "burned-in" at factory
  - **volatile:** data is lost when power is cut
  - **non-volatile:** data is stored even when there is no power
- **Network Connection:** Connects computers to other computers and the Internet; new addition
- **User Interface Devices:** Essential input/output devices to allow communication between the computer and the user
  - i.e. keyboard, mouse, monitor
- **Auxiliary Input/Output Devices:** Secondary input/output devices not necessary to operate a computer; "nice to haves"
  - i.e. speakers, printer, camera
- **Auxiliary Storage Devices:** Stores data and instructions long-term; rewritable and non-volatile
  - i.e. USB flash drive, hard drive, DVD-R / DVD+RW

## Binary System

- Used because computers rely on transistors, which have two states (on or off)
- **byte:** a group of 8 bits
- **positional numbering system:** position of each number has an assigned value (i.e. $2^0, 2^1, 2^2$)
- **kilobyte:** ~1,000 bytes
- **megabyte:** ~1 million bytes
- **gigabyte:** ~1 billion bytes
- **terabyte:** ~1 trillion bytes

## ASCII vs Unicode

- Computers use an encoding scheme to map binary numbers to a letter
- Unicode introduced to overcome language and space limit of ASCII
- Unicode is universal standard for character encoding
- Used to represent human-readable text for processing by computers

|ASCII|Unicode|
|-|-|
|Character encoding standard for electronic comm.|Computing industry standard for consistent encoding, representation, and handling of text in most of world's writing sys.|
|American Standard Code for Information Intercharge|Universal Character Set|
|Supports 128 chars.|Wide range of chars.|
|7 (later 8) bits to represent char.|8, 16, or 32 bits used to encode a char.
|Less space|More space|
|Only English/Latin characters|Characters of any language as well as emojis and symbols|

## Conversions between Binary and Decimal

### Binary (base-2) to Decimal (base-10)

Example used: 11011001

1. Map each digit to its corresponding decimal representation

|1|1|0|1|1|0|0|1|
|-|-|-|-|-|-|-|-|
|$2^7$|$2^6$|$2^5$|$2^4$|$2^3$|$2^2$|$2^1$|$2^0$|
|128|64|32|16|8|4|2|1|

2. Find the sum of all the decimal representations of the digits that are '1'

$$
\begin{equation*}
128 + 64 + 16 + 8 + 1 = 217
\end{equation*}
$$

$\therefore$ 11011001 in decimal is 217

### Decimal to Binary

Example used: 217 (for consistency)

1. Divide the number by 2
2. Record quotient and remainder (0 or 1) of number
3. Repeat steps 1 and 2 where the number is the quotient found. Repeat until quotient reaches 0.
4. Assemble the remainders in reverse order they have been found

$$
\begin{gather*}
217 \div 2 = 108 \text{ R } 1 \\
108 \div 2 = 54 \text{ R } 0 \\
54 \div 2 = 27 \text{ R } 0 \\
27 \div 2 = 13 \text{ R } 1 \\
13 \div 2 = 6 \text{ R } 1 \\
6 \div 2 = 3 \text{ R } 0 \\
3 \div 2 = 1 \text{ R } 1 \\
1 \div 2 = 0 \text{ R } 1 \\ \\
\therefore 217 = 11011001
\end{gather*}
$$
