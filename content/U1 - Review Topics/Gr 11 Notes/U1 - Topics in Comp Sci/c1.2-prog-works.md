# C1.2 - How Programming Works

## Communicating with Computers

- **machine code:** the first 'language' hardwired into the processor consisting of only 1s and 0s
  - processor consists of electrical switches called transistors
- specific combination of bits perform a specific task on the processor (hardwired instructions)
- 1949: first prog. language assembly created to map processor instructions to human-readable language
- first assembler had to be written directly in machine code

## First Generation Languages

- Instructions written in **machine code**
- CPUs from diff. manufacturers or standards interpret patterns differently
- Machine dependent

**Machine Code Steps**

1. ***Fetch*** next instruction in program
2. ***Decode*** instruction to determine operation to perform
3. ***Execute*** the instruction

## Second Generation Languages

- Machine language no longer used
- Assembly language used instead
- Short mnemonic words used instead
- Each brand of CPU had its own assembly language
- Machine dependent

## Third Generation Languages

- Machine independent program
- Can usually run on any CPU brand
- First appearance: 1950s with devel. of FORTRAN and COBOL
- Considered "high-level" languages
- Modern high-level lang: C++, Python, JavaScript
  
## Programming Building Blocks

- **keyword:** words to define instructions, variables, structures, etc.
  - differs by language
- **operator:** mathematical instruction
- **statement:** complete instruction following syntax rules

## Compiler vs. Interpreter

**compiler:** program that converts language into machine code at once

**interpreter:** program that goes over code and converts it to machine code line-by-line &mdash; direct execution

|Compiler|Interpreter|
|-|-|
|Takes entire program in one go|Takes a line of code at a time|
|Generates intermediate machine code|Never produces intermediate machine code|
|Best suited for production|Best suited for SEng env. / prototyping|
|C, C++, C#, Scala, Java, etc.|Python, PHP, Perl, Ruby, etc.|

## Cryptography

**cryptography:** a method of scrambling data so that only the intended recipient can read the data
