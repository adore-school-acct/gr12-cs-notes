# C1.2 - Functions

## Functions

- **function:** named group of statements that perform a specific task
- Advantages to using Functions
	1. Code Reuse
	2. Simpler Code
	3. Easier Debugging (debug once instead of many times)
	4. Supports Teamwork
- **abstraction:** hide away the little details

## Structure

- **function header:** beginning of a function definition &mdash; defines name and parameters
- **block:** set of statements that belong together as a group

## Example

```py
def chorus():
	'''This function sings the chorus of Old MacDonald had a farm.'''
	print("Ee-igh, ee-igh, oh")
	print()

chorus()
```

**Order of Execution**

1.  Line above `chorus()`?
2. `chorus()`
3. `def chorus():`
4. Line-by-line under `def chorus():`
5. End of `chorus()`

## The `main()` Function

- The main function
- Contains mainline logic
- **mainline logic:** overall logic of program
- `main()` must be called at the bottom

```py
def main():
	chorus()

def chorus():
	'''This function sings the chorus of Old MacDonald had a farm.'''
	print("Ee-igh, ee-igh, oh")
	print()

if __name__ == "__main__":
	main()
```

## Scope

- **scope:** part of a program where a variable may be accessed
- **local variable:** variable that belongs to the function it was created
	- all variables in a function are local
- **global variable:** variable that can be accessed by the entire program

## Passing Data to Functions

- **argument:** any piece of data passed into a function when function is called
- **parameter:** variable assigned the value of an argument when a function is called
- *Programmers use argument and parameter interchangeably*
- **pass-by-value** or **pass-by-copy**: function cannot change the original value of the variable

### Example

```py
def main():
	value = 5
	double(value) # Passing in value

def double(n):
	n *= 2
	print("Double is %d" % n)

if __name__ == "__main__":
	main()
```

## Passing Multiple Arguments (Positional v. Keyword)

- **positional parameter:** parameter whose order matter
- **positional argument:** argument whose position matters when a function is being called
- **keyword argument:** allows you to specify a parameter value for an argument

```py
def main():
	birthday("Adore", 17) # positional argument
	birthday(name="Bob", age=0) # keyword argument

def birthday(name, age):
	print(f"Happy birthday {name}! You are {age} years old.")

if __name__ == "__main__":
	main()
```

*Will return error*

```py
def add(n1, n2):
	return n1 + n2

print(add(n1=7, 5))
```

Keyword arguments must come **AFTER** positional arguments

## Setting Default Values

```py
def function(value=69): # = 69 sets value to 69
	print(value)
	
def func(a=7, b): # <-- returns error
	print(a * b)

...
```

**NOTE:** Any parameter with default value needs to be listed AFTER all the parameters that DO NOT have default values

## Passing in Functions to Functions

```py
def with_string(func, string):
	func(string)

with_string(print, "Hello World")
```

## Global Variables: Bad Design

- **global variable:** variable accessible outside of function
- **global constant:** global variable where value is NOT changed
	- useful in rare cases like fps for an entire game
	- use UPPERCASE letters

Global variables in function must be accessed using the `global` keyword

```py
value = 69

def main():
	global value
	print(value)

if __name__ == "__main__":
	main()
```

### :x: Problems with Global Variables

- make programs harder to understand and debug
- if function relies on global variable, then in new program, the variable must be copied over in addition to the function
- external data should be passed in as argument

## Passing List to Function

- **pass-by-value / pass-by-copy:** pass a copy of the original value into the function
- **pass-by-reference:** a reference ("address") to the original list to passed to the function, the list is not duplicated
	- all mutable objects passed like this
	- done this way for space and time efficiency
	- note that when setting another variable as a list variable
		- the variable is set to the reference of the new list
	- setting a variable (even if new name) to a new list creates a new list

```py
# Demonstration of pass-by-reference

def double_list(nums):
	for i in range(len(nums)):
		nums[i] *= 2

	return nums

nums = [1, 2, 3, 4]
doubled = double_list(nums)
print("nums:", nums)
print("doubled:", doubled)
```

A `return` statement is not needed if pass-by-reference is used

### Force Pass-by-Copy

- Pass in a slice of the list into the function
- Format: `function_name(list_name[:])`
- The list contents are modified but not the list itself
- :x: Should not do unless you have specific reason to copy
